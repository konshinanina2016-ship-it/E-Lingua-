🐼 Пиньинь-парк

Кроссворд: прочитайте русскую подсказку и впишите ответ пиньинем без пробелов и тонов в поле рядом с ней. Выберите поле, чтобы увидеть нужные клетки. Поиск слов: нажмите первую и последнюю букву слова пиньиня по прямой — горизонтально, вертикально или по диагонали. Можно выбирать в обратном порядке. В словарике есть иероглифы, пиньинь с тонами и русский перевод. Для ü в ответах используется v. «Ответы» открывают решение после подтверждения. Результат сохраняется в этом браузере, если он разрешает локальное хранение. Поле поиска слов автоматически помещается по ширине экрана; двигать сетку не нужно.

🧩 Кроссворд панды

Прочитайте русскую подсказку и впишите пиньинь латинскими буквами без пробелов и тонов. Для ü используйте v: lǜsè → lvse. Нажмите на поле ответа, чтобы увидеть его клетки.
